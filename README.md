# Investing for Programmers 学习工作区

这个目录用于系统化学习 Stefan Papp 的 *Investing for Programmers*。

## 你应该从这本书获得什么
- 一套投资世界的基础地图：`stocks`、`bonds`、`ETF`、`crypto`、`derivatives`、`private equity`
- 一套读财务数据的最小能力：`income statement`、`balance sheet`、`free cash flow`、常见 `ratios`
- 一套程序员视角的方法论：用数据、脚本、notebooks、API、AI、agents 辅助研究
- 一套风险意识：组合、仓位、相关性、`VaR`、对冲、人的偏差
- 一套可复用的研究流程：提出 thesis、验证 thesis、记录假设、复盘结果

## 这五大块分别在学什么
- 投资世界的基础地图：先搞清楚有哪些资产和策略，不急着下判断。
- 财务与数据阅读能力：学会看财务、看指标、拿数据，不再只听故事。
- 程序员视角的方法论：把脚本、自动化、AI、agents 放进研究流程。
- 风险意识：学会先想“错了怎么办”，而不是只想“赚多少”。
- 可复用的研究流程：把前面内容收束成自己的最小研究系统。

更完整的总览见 [全书总笔记.md](/Users/gmet/Projects/learning/Investing-for-Programmers/全书总笔记.md)。

## 建议的学习方式
- 先掌握框架，再补细节，不要一开始陷入指标堆。
- 每学完一章，至少回答三个问题：
  1. 这一章解决什么决策问题？
  2. 这一章给了我哪些可执行的方法？
  3. 哪些内容适合我现在就实践？
- 对不熟的金融术语，优先掌握“用途”和“局限”，再追求定义的精确。
- 默认采用 `轻标注 + 外部笔记`：PDF 里只标关键原文，理解、问答和结构化结论沉淀到项目文档；如果主读文件是 PDF，预标注默认直接覆盖回主读文件，覆盖后默认只保留这一份 PDF。
