## Chapter 1: The analytical investor

### 资产与回报

- 债券（bond）：本质上是一张借条。你把钱借给政府或公司，对方按约付息，到期还本。
- 股票（stock）：公司所有权的一部分。买股票，本质上是在买一小部分公司的权益。
- 股权 / 所有者权益（equity）：强调“你拥有公司的一部分”这个视角。谈 `equity` 时，重点是所有权，不只是价格波动。
- 份额 / 股数（share）：可计数的一份持有单位。`stock` 更偏资产整体概念，`share` 更偏你具体持有了多少份。
- 资产（asset）：能带来未来价值、现金流或升值可能的东西，不只限于金融产品。
- 证券（security / securities）：金融领域里可投资、可交易的一类资产总称，比如股票、债券、ETF、期权等。
- 资本增值（capital appreciation）：资产价格上涨带来的收益，核心是“以后更贵了”。
- 被动收入（passive income）：资产持续给你带来的现金流，比如利息、股息、租金、staking 奖励。

### 收益、利率与收益率

- 收益率（yield）：你投入一笔钱后，按当前价格看，能拿到多高比例的现金回报或利息回报。看到 `yield`，先问“这是哪种资产的哪种回报率”。
- 股息（dividend）：公司把利润中的一部分按每股发给股东的现金分配。
- 股息率（dividend yield）：一年股息相对于当前股价的比例。它描述的是“靠分红能拿到多少现金回报”，不等于股票总回报。
- 票息（coupon）：债券定期支付给持有人的利息。
- 债券收益率（bond yield）：持有一只债券时，你按当前市场价格能获得的回报率。它和票息有关，但不完全等于票息。
- 到期日（maturity date）：债券约定归还本金的时间点。
- 本金（principal）：你最初借出去或投入的那部分钱。
- 面值（face value）：债券在到期时通常按约归还的名义金额。
- 无风险收益率（risk-free rate）：金融里常用来做比较基准的收益率，通常拿美国国债近似表示。更准确地理解，应是“极低违约风险的基准回报”，不是真的完全没风险。

### 风险与组合

- 风险承受能力（risk tolerance）：你能承受多大波动和回撤而不把策略执行搞乱。
- 信用风险（credit risk）：借钱给别人后，对方还不上钱的风险。
- 分散化（diversification）：不要把风险压在单一资产或单一判断上，而是通过组合来降低被单点失误打穿的概率。
- 投资组合（portfolio）：你持有的一篮子资产，不只是股票，也可以包括债券、ETF、期权等。
- 仓位（position）：你在某个具体资产上的持有暴露。
- 多头（long / long position）：先买入资产，赌它以后会涨。价格上涨时，多头赚钱；价格下跌时，多头亏钱。可以先记成“先买后卖”。
- 空头（short / short position）：先借来资产卖出，赌它以后会跌，再用更低价格买回来还掉。价格下跌时，空头赚钱；价格上涨时，空头亏钱。可以先记成“先卖后买”。
- 未实现收益 / 浮盈（unrealized gain）：账面上已经赚钱，但你还没卖出，收益还没有真正锁定。
- 未实现亏损 / 浮亏（unrealized loss）：账面上已经亏钱，但你还没卖出，亏损还没有真正落地。

### 常见资产类型

- 交易型开放式指数基金（ETF, exchange-traded fund）：一篮子资产打包成一个可交易产品。它的核心用途是更低成本地做分散化。
- 共同基金（mutual fund）：也是一篮子资产，但通常按收盘后的净值成交，不像 ETF 那样盘中实时交易。
- 对冲基金（hedge fund）：面向更高净值或机构投资者、策略更激进的一类基金。重点不是“更厉害”，而是约束更少、风险也通常更复杂。
- 外汇（foreign exchange / forex）：不同货币之间的兑换市场。核心不是公司经营，而是货币相对价格变化。
- 加密货币（cryptocurrency）：建立在区块链上的数字资产。先理解它试图解决什么交易和信任问题，再看投资逻辑。
- 区块链（blockchain）：一种分布式账本技术。它是底层技术，`cryptocurrency` 是它最常见的一类应用。
- 衍生品（derivative）：价值依附于其他资产的合约。它常被用来放大收益、管理风险，或者做价格方向押注。
- 期权（option）：一种赋予你未来按特定价格买入或卖出某资产“权利而非义务”的合约。
- 看跌期权（put option）：给买方在未来按约定价格卖出的权利，常被用作下跌保护。
- 看涨期权（call option）：给买方在未来按约定价格买入的权利，常被用来押注上涨。
- 行权价（strike price）：期权合约里约定的买入或卖出价格。
- 权利金（premium）：买期权时先支付的费用，可以把它理解为购买这个“权利”的价格。
- 私募股权（private equity）：投资未上市公司。流动性更差、信息更少，但潜在回报和不确定性都更高。

### 研究与方法

- 分析型投资者（analytical investor）：不是凭感觉下注，而是尽量用数据、逻辑、证据和过程做判断的人。
- 数据驱动投资者（data-driven investor）：强调先看证据、再下结论，而不是先有结论再找理由。
- 定量研究（quantitative research）：把财务和其他可量化数据转成比较、筛选和评分。
- 定性研究（qualitative research）：研究数字背后的原因、质量、竞争格局、管理层、品牌和情绪语境。
- 投资论点 / 投资假设（investment thesis）：你为什么投一个资产的核心论证。它应该能写清楚证据、假设、风险和反证。
- 资产监控（asset monitor）：持续汇总持仓、价格、事件和指标的系统，作用是减少靠记忆管理投资。
- 回测（backtesting）：用历史数据检验一个策略过去会怎样表现，作用类似策略版的历史单元测试。
- 对冲（hedging）：通过反向或相关头寸来降低组合受到特定风险冲击的幅度。

## Chapter 2: Investment essentials

### 财务报表基础

- 财务报表（financial statements）：公司用标准化方式披露经营情况的文件集合。对投资者来说，它们是读公司状态的基础输入。
- 利润表 / 损益表（income statement）：看一段时间内公司赚了多少、花了多少、最后剩多少。它更像“这段时间跑出来的结果”。
- 资产负债表（balance sheet）：看某个时点公司拥有什么、欠了什么、净剩多少。它更像“当前系统状态快照”。
- 现金流量表（cash flow statement）：看这段时间公司真实进了多少现金、出了多少现金。它比利润更接近“钱有没有真正到手”。
- 自由现金流（free cash flow, FCF）：公司在经营产生现金之后，扣掉维持或扩张业务所必需的资本开支，最后真正还剩下多少可自由支配的现金。它比利润更接近“公司还能拿多少钱去还债、分红、回购或再投资”。
- 收入 / 营收（revenue）：公司通过卖产品或服务带来的总收入。
- 成本（cost of goods sold, COGS）：为了生产和交付产品/服务直接花掉的成本。
- 费用（expenses）：公司为了运转而发生的各类支出，不只包括生产成本。
- 运营费用 / 经营费用（OpEx, operating expenses）：为了维持日常经营而持续发生的费用，比如工资、租金、营销、管理费用、部分研发支出等。它更像“把业务每天跑起来要花的钱”。
- 资本开支（CapEx, capital expenditure）：为了买入、建设或升级长期资产而发生的支出，比如建厂、买设备、购置服务器等。它通常不是日常运营小额费用，而是面向更长期能力建设的投入。
- 研发（R&D, research and development）：公司为了研发新产品、提升技术、训练能力或扩展未来业务而投入的支出。它不一定马上带来收入，但通常关系到公司未来的竞争力。
- 毛利润（gross profit）：收入减去直接成本后剩下的利润，反映产品或服务本身的赚钱能力。
- 营业利润（operating income）：主营业务扣除经营相关成本后留下的利润，更接近核心业务表现。
- 净利润（net income）：收入减掉所有成本、费用、税等之后的最终利润。
- 时间价值（time value of money）：今天的一块钱比未来的一块钱更值钱，因为今天的钱可以投资、也会受通胀影响。

### 行业与规模

- 行业分类（industry classification）：把公司按业务类型归到不同类别，用来找到可比较的同行。
- 全球行业分类标准（GICS, Global Industry Classification Standard）：常见的行业分类体系之一，用来把公司归入 sector 和 industry。
- 板块 / 大行业（sector）：较大的行业类别，比如科技、金融、能源。
- 行业 / 细分行业（industry）：比 sector 更细的一层，用来找更接近的业务可比对象。
- 经济周期（economic cycle）：经济扩张、放缓、衰退、复苏这类宏观阶段。不同板块在不同周期里表现会不一样。
- `cap`：在投资语境里通常是 `capitalization` 的简写，不是单独一个新概念。比如 `market cap` 就是 `market capitalization`（市值）。
- 市值 / 市场资本化（market capitalization / capitalization）：公司股价乘以总股数，反映市场给这家公司的整体定价规模。
- 超大盘股（mega-cap）：市值非常大的公司，通常指几千亿美元级别以上的巨头公司。
- 大盘股（large-cap）：市值较大的公司，通常业务更成熟、波动相对小一些。
- 中盘股（mid-cap）：处于中间规模的公司，常被看作介于成熟和成长之间。
- 小盘股（small-cap）：市值较小的公司，潜在成长空间和波动通常都更大。
- 微盘股（micro-cap）：市值很小的公司，流动性、波动和不确定性通常都更高。

### 比率与指标

- 比率（ratio）：把两个财务数字做成可比较的比例，帮助快速判断公司的某个维度。
- 流动性（liquidity）：公司短期拿出现金应付账单、利息和短期债务的能力。
- 流动性比率（liquidity ratio）：衡量公司短期偿付能力的一类指标总称。
- 流动比率（current ratio）：流动资产相对于流动负债的比例，用来看公司短期资产够不够覆盖短期债务。
- 速动比率（quick ratio）：比流动比率更严格的短期偿付指标，会排除库存这类不能立刻变现的项目。
- 债务（debt）：需要偿还、通常带利息的负债。对债券投资者尤其关键。
- 资产负债率 / 杠杆（leverage）：公司用多少债务来撬动资产或经营的程度。
- 债务股本比（debt-to-equity, D/E）：总负债相对于股东权益的比例，用来看公司对债务融资依赖有多高。
- 利息保障倍数（interest coverage ratio）：公司利润覆盖利息支出的能力。它是在问“赚的钱够不够付利息”。
- 盈利（earnings）：公司赚到的钱，通常是利润相关概念的统称。
- 每股收益（earnings per share, EPS）：把公司的盈利按“每一股普通股”重新表达后的结果。它更方便投资者从持股视角理解盈利能力，也是 `P/E` 的基础。
- 每股自由现金流（free cash flow per share）：把自由现金流平均分到每一股后的结果，更接近每股真正对应的现金创造能力。
- 优先股股息（preferred dividends）：优先股股东优先获得的分配。在计算普通股股东视角的 `EPS` 时，通常要先扣掉这部分。
- 流通在外股数（shares outstanding）：当前市场上实际存在、用于分摊公司权益和盈利的普通股数量。
- 估值（valuation）：市场现在给这家公司定了多高的价格，以及这个价格相对业绩是贵还是便宜。
- 市盈率（price-to-earnings, P/E）：股价相对于每股收益的倍数，是最常见的估值指标之一。
- 预期市盈率（forward P/E）：用未来预期盈利计算的市盈率，更接近市场对未来的定价。
- 历史市盈率（trailing P/E）：用过去已经实现的盈利计算的市盈率，更接近基于历史业绩的定价。
- 市盈增长比（price/earnings-to-growth, PEG ratio）：把 `P/E` 和盈利增长速度结合起来看的指标，用来补足“只看 P/E 不看增长”的问题。
- 市销率（price-to-sales, P/S）：市值或股价相对于销售收入的比例，常用于利润还不稳定但收入增长快的公司。
- 市净率（price-to-book, P/B）：市场价格相对于公司账面净资产的比例，对资本密集型公司更常见。
- 贝塔值（beta）：股票相对于整体市场的波动程度。更像风险 / 波动指标，不是经营质量指标。
- 盈利能力（profitability）：公司把收入变成利润的能力。
- 利润率（margin）：每赚一块钱收入，能留下多少利润。
- 资产回报率（return on assets, ROA）：公司利用资产创造利润的效率。
- 股本回报率（return on equity, ROE）：公司用股东投入的资本赚钱的效率。
- 股息（dividend）：公司把利润中的一部分分给股东的现金。
- 股息增长率（dividend growth rate）：公司分红随时间增长的速度，用来看分红是否有延续性。
- 分红能力 / 分红可持续性（dividend sustainability）：公司未来是否有能力持续维持当前分红水平。
- 股息支付率 / 派息率（payout ratio）：利润中有多少比例被公司拿来分红，用来看当前分红压力和可持续性。

### 外部判断

- 外部评估（external assessments）：由第三方机构给出的评价、评分或预测，能参考，但不能替代自己的判断。
- 评级（ratings）：外部机构基于风险和质量给公司的分数或等级。
- 目标价（target price）：分析师对未来股价的预测值，带有很强主观性和不确定性。
- 内在价值（intrinsic value）：资产在基本面意义上“应该值多少钱”的判断，不等于当前市场价格。
- 机会成本（opportunity cost）：把钱、时间或资源投入 A，就意味着不能同时投入 B；放弃的那个更好替代方案的价值，就是机会成本。
- 总拥有成本（total cost of ownership, TCO）：一个方案从采购、部署、维护到长期运行的全部成本总和。它不是只看买入价格，而是看整个生命周期到底要花多少钱。

### 方法与判断

- 假设（hypothesis）：基于当前证据提出的解释或判断，不是最终真理。
- 看多假设（bullish hypothesis）：认为公司或资产未来更可能向好的那套解释。
- 看空假设（bearish hypothesis）：认为公司或资产未来更可能恶化的那套解释。
- 基本面（fundamentals）：公司的业务、财务、竞争力、现金流等底层情况。
- 同行比较（peer comparison）：把公司放到相近行业、相近模式的公司里比较，而不是乱找参照物。

## Chapter 3: Collecting data

### 数据类型

- 金融数据（financial data）：用于分析资产、公司和市场状态的数据总称。先别把它当一种数据看，它内部就分很多层。
- 基本面数据（fundamental data）：来自财务报表、公司披露和经营指标的数据。它更像在回答“公司底子怎么样”。
- 技术数据（technical data）：价格、成交量、收益率、波动等市场交易数据。它更像在回答“市场过去怎么给它定价”。
- 非财务数据（nonfinancial data）：新闻、舆情、文本、管理层表达、情绪等不直接来自报表和价格序列的数据。它更像在补充数字背后的语境。

### 平台与接入

- 金融分析平台（financial analysis platform）：提供价格、报表、筛选器、图表或研究信息的平台。它适合浏览和探索，不一定适合作为稳定程序接口。
- 股票筛选器（stock screener）：按市值、行业、估值、盈利等条件先筛出候选股票的工具。它的作用不是给答案，而是先缩小搜索空间。
- 应用程序编程接口（API, application programming interface）：程序与外部服务交换数据的正式接口。对程序员来说，它比直接抓网页更适合做稳定流程。
- 网页抓取（web scraping）：直接从网页结构里提取数据的方法。能用，但通常更脆弱，因为页面结构和反爬策略可能变化。
- 股票代码（ticker）：交易所里用于识别某个证券的短标识。它不是全局唯一真理，跨平台时还要注意交易所后缀和命名差异。
- 交易所（exchange）：证券挂牌和交易发生的市场场所，比如 NASDAQ、NYSE、LSE。很多 API 会用自己的缩写来表示它们。

### 研究环境与库

- 数据科学 notebook（data science notebook）：按单元格执行代码并即时查看结果的交互式环境。它特别适合探索式分析，而不是一上来就做完整产品。
- Jupyter：最常见的 notebook 环境之一。对个人研究来说，它是低门槛、反馈快的实验台。
- Databricks：更偏团队化和数据工程化的数据分析平台，也支持 notebook 工作流。
- `yfinance`：常见的开源金融数据 Python 库，常被用来从 Yahoo Finance 相关来源抓取数据。它很适合入门和原型，但稳定性依赖上游。
- `OpenBB`：面向金融研究的工具生态，支持多类资产和多数据提供方。它的价值不只是拿股票数据，而是帮你搭更统一的研究入口。

### 时间序列与统计

- 历史价格（historical prices）：某资产在过去一段时间内的价格序列。它是做技术分析和回测的最基本输入。
- 调整后收盘价（adjusted close）：对分红、拆股等事件做过调整后的收盘价，更适合做长期收益率分析。
- 简单收益率（simple returns）：直接用当前价格相对上一期价格的变化比例来算收益率的方法。
- 对数收益率（logarithmic returns）：对价格比值取对数后的收益率表示方式，更适合很多统计分析场景。
- 均值（mean）：一组数据的平均水平。放在价格或收益序列里时，它更像“中心值”。
- 标准差（standard deviation, std）：衡量数据围绕均值波动有多大。投资里常被当作波动强弱的近似指标。
- 方差（variance, var）：标准差的平方，表示偏离均值的离散程度。

### 商业数据源与权限

- 商业库 / 商业数据源（commercial libraries）：由商业公司维护的数据服务或 SDK。你通常是在为稳定性、覆盖面、速度或服务边界付费。
- 免费增值模式（freemium）：基础功能免费，更高额度或更完整功能收费的商业模式。
- API 密钥（API key）：调用外部服务时用于识别和授权的密钥。它不是代码常量，应该像凭证一样管理。
- `Finviz`：以美股筛选器闻名的平台和数据入口，对美股筛选很强，但市场覆盖不全面。
- `EODHD`：提供历史行情和多交易所覆盖的数据服务，接口风格和常见 Python 工作流比较接近。
- `Alpha Vantage`：提供时间序列和其他市场数据的 API 服务，免费版可用，但高级能力受订阅限制。

## Chapter 10: Charts and technical analysis

### 图表与技术分析

- 蜡烛图（candlestick）：把一段时间内的开盘价、最高价、最低价、收盘价压进一根图形里。它的价值不是“看起来专业”，而是比折线图多表达了价格结构和波动范围。
- 移动平均线 / 均线（moving averages / moving average）：把最近一段时间的价格做平均，形成更平滑的趋势线。它的作用是降低单日噪声，让你更容易看趋势。
- 简单移动平均线（simple moving average, SMA）：对窗口内每个价格一视同仁地取平均，最直觉、最常见。
- 指数移动平均线（exponential moving average, EMA）：给更近的价格更高权重，因此对新变化更敏感。
- 移动平均线收敛发散指标（moving average convergence divergence, MACD）：一种基于均线差异的动量指标。先把它理解成“看趋势动量是在增强还是减弱”的工具，而不是神奇买卖按钮。
- 支撑线（support line）：价格不容易跌破的区间，反映“到这里时买盘或心理支撑变强”的直觉。
- 阻力线（resistance line）：价格不容易突破的区间，反映“到这里时卖盘或心理压力变强”的直觉。
- 突破（breakout）：价格穿过支撑或阻力的位置。它常被技术分析者当成一个重要信号，但不保证后面一定顺着走。
- 一目均衡表 / 一目云图（Ichimoku Cloud）：把趋势、动量、支撑、阻力揉在一张图里看的综合图表工具。先把它理解成“不是一条线，而是一套图层”。
