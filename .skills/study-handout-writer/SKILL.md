# Study Handout Writer

Write the handout as a teaching guide, not as a compressed note dump.

## Workflow

1. Start from the source material, not only from prior summaries.
   - Read the chapter note if it already exists.
   - Re-check the source PDF evidence used for the chapter.
   - Make sure important examples, figures, tables, formulas, and listings are visible in your working context.

2. Preserve the chapter's teaching path.
   - Explain what the chapter is trying to train.
   - Keep the main example chain.
   - Keep the distinction between:
     - core concept
     - example
     - warning or limitation

3. Mark original positions aggressively.
   - For important items, include:
     - PDF page
     - figure, table, or listing id when available
     - whether the learner should first look at the definition, the example, or the result
   - If the book does not provide a clean closed-form formula and instead uses definition, code, or a chart, say so explicitly.

4. Optimize for first-pass readability.
   - Use short sections.
   - Prefer direct explanations over taxonomy.
   - Explain terms by function first.
   - Include concise “why this matters” framing.

5. End with guided return-to-original pointers.
   - Tell the learner which parts are most worth re-reading in the original.
   - Prefer a short prioritized list rather than exhaustive coverage.

## Content Rules

- Write in Simplified Chinese by default.
- Keep technically important English terms inline.
- Do not turn the handout into a changelog of the chapter note.
- Do not drop the chapter's main example just because it is lengthy.
- When in doubt, preserve the example and shorten surrounding commentary.
