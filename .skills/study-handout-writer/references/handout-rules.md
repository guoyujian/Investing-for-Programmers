# Handout Rules

## Required Outcomes

The handout should help a learner complete a first pass without opening the original immediately.

It should always make the learner leave with:

- the chapter's main line
- the key concepts
- the important example chain
- the most important original positions to revisit later

## Position Marking

For important original items, include:

- PDF page number
- figure or table id
- listing id
- whether to look at the definition, example, code, or result first

## Example Preservation

Do not replace the author's major example with a generic explanation.

Good pattern:

- explain what the example is doing
- explain why the author chose it
- explain what general rule the example is teaching

## Formula Rule

If the original chapter does not present a highlighted formula, say so clearly.

Example:

- "This concept is presented through definition plus code example rather than a stand-alone formula."

## Tone

- teach, do not merely summarize
- reduce friction, do not flatten nuance
- be friendly to a first-pass learner
